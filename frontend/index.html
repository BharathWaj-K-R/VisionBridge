Why VisionBridge

Built around a real inference pipeline.

The prototype combines browser-side landmark extraction with a frozen pose+face Transformer and optional signer-specific adapters.

Real pipeline

Camera frames are processed by MediaPipe Holistic before a backend inference request is made.

Signer adapters

Optional BridgeAdapter weights are intended to personalize a frozen base model.

Controlled data flow

Raw camera frames remain in the browser; extracted keypoints are sent to the configured inference API.

Evidence first

The interface avoids presenting benchmark numbers that have not been verified for the current checkpoint.

Technology

A measurable model pipeline.

VisionBridge uses 132 pose features and 1404 face features per frame, followed by a pose+face fusion Transformer and greedy CTC decoding.
